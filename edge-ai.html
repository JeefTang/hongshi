Why on site instead of in a cloud

Plant data — P&ID sets, maintenance logs, meter readings, operator notes, photographs of a failed bearing — is exactly the data that a security review will not let out of the building. An agent that needs the internet to answer a question about a pump is an agent that will not be deployed.

This appliance answers locally. The model, the documents, the conversation history and the tool results all stay inside the plant network. There is no per-token bill and no dependency on a vendor staying in business or keeping an API online.

Measured, not estimated. The performance figures on this page were recorded on our reference unit: 4-way concurrent generation at 8K context per session, 10.4–10.9 tokens/s per stream, NPU utilisation reaching 99%, hottest point 52 °C, about 1.5 GB of the 15.6 GB memory in use.

What the agent actually does

  • Answers from your documents. Manuals, commissioning reports, contracts, test sheets — indexed locally, answered with the source cited.
  • Reads what is on site. Photographs and scanned nameplates are read by on-board NPU OCR, so a picture of a pump nameplate becomes structured data.
  • Runs scheduled work. Daily energy summaries, shift handover notes, meter comparisons, overdue-maintenance lists — generated and pushed to the people who need them.
  • Talks to the systems you already have. Modbus, MQTT and HTTP interfaces for meters, PLCs and monitoring platforms.
  • Connects to your messaging. WeChat, Feishu, Telegram or email — the same agent, reachable from a phone on the plant network.

Deployment

The appliance is delivered configured, with the model loaded and the agent runtime installed. Commissioning is a network drop and an account setup, not a software project.

  • Runs fully offline; internet is optional, for updates and remote support only
  • Local accounts and role-based access, with an audit log of every agent action
  • Document ingestion done on site — files are not uploaded anywhere
  • Optional site-to-site VPN for vendor support, enabled by the plant when needed
  • Model and knowledge base can be updated from a USB device, no network required

What it is not

It is not a replacement for a plant historian, a DCS or a safety system. It reads, summarises and drafts; it does not close a control loop, and it is not connected to protection logic.

It is also not an unlimited model. A 27B model on edge silicon is a capable assistant for engineering and reporting work — it is not a frontier model, and we do not present it as one. The value is that it runs here, on your data, at a fixed cost, with no network dependency.

Standard hardware, engineered deployment

The appliance is built on Rockchip's standard edge product family — an RK3588 host with RK1828 accelerator modules, the same silicon any integrator can buy. The hardware is not the product.

What we deliver is everything above it: the model chosen and quantised for the duty, the OpenClaw agent runtime, the document index, the tool connections, the prompts and the guardrails that make it answer like a plant engineer instead of a chatbot — plus the people who pick up the phone when it does not.

Same box, your brand. For distributors and system integrators we ship the appliance configured and tested, with your nameplate, your start screen and your support contact. You sell it into your market; we keep the runtime and the knowledge base current.
